# 📐 VolumeAreaApp2

A user-friendly application to compute **areas and volumes** of common 2D and 3D shapes. Designed for students, educators, and professionals, this project provides accurate geometrical calculations with minimal effort.

## 🚀 Features

✔️ Calculate **area** of shapes such as:
* Square
* Rectangle
* Circle
* Triangle

✔️ Calculate **volume** of solids such as:
* Cube
* Rectangular Prism (Cuboid)
* Cylinder
* Sphere

✔️ Simple and intuitive user interface
✔️ Input validation with helpful error messages
✔️ Results displayed clearly with units

---

## 🧠 Motivation

Understanding geometric properties like area and volume is essential in math, engineering, architecture, and science. This app simplifies those computations and can be used as an educational tool or quick reference.
