# 📐 VolumeAreaApp2

A user-friendly application to compute **areas and volumes** of common 2D and 3D shapes. Designed for students, educators, and professionals, this project provides accurate geometrical calculations with minimal effort.

## 🚀 Features

✔️ Calculate **area** of shapes such as:
* Square
* Rectangle
* Circle
* Triangle

✔️ Calculate **volume** of solids such as:
* Cube
* Rectangular Prism (Cuboid)
* Cylinder
* Sphere

✔️ Simple and intuitive user interface <br/>
✔️ Input validation with helpful error messages <br/>
✔️ Results displayed clearly with units

---

## 🧠 Motivation

Understanding geometric properties like area and volume is essential in math, engineering, architecture, and science. This app simplifies those computations and can be used as an educational tool or quick reference.

## 📦 Getting Started

### Prerequisites

Ensure you have:

* Android Studio installed
* A working Android device or emulator
* Java/Kotlin support enabled

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/tarun3695/VolumeAreaApp2.git
   ```
2. Open in Android Studio
3. Build & Run on your device or emulator

---

## 📋 Usage

1. Launch the app
2. Select the shape type
3. Enter required dimensions
4. Tap **Calculate**
5. View the result
